# Google Play Release Checklist

- [ ] Confirm final product name and unique application ID.
- [ ] Target Android 16 / API 36 for submissions subject to the 31 August 2026 requirement.
- [ ] Build a signed Android App Bundle.
- [ ] Enable Google Play App Signing.
- [ ] Create a separately protected upload key.
- [ ] Host privacy policy publicly.
- [ ] Complete Data Safety truthfully.
- [ ] Complete content rating and target audience.
- [ ] Declare NFC hardware requirement.
- [ ] Explain that MIFARE Classic support varies between phones.
- [ ] Provide support email and open-source website.
- [ ] Add phone and tablet screenshots.
- [ ] Add feature graphic, icon and store descriptions.
- [ ] Run closed testing with real K2 Pro/CFS users.
- [ ] Review pre-launch report on multiple Android versions.
- [ ] Publish third-party notices and source code for the exact release.
- [ ] Do not publish tag writing until the device-compatibility gate (H-000) and blank-tag sector-trailer path (H-011) are bench-verified on real hardware — H-001 (the codec itself) is resolved as of 0.2.0.
